# DRIP RACE — approved grass ground material

Four 2048×2048 textures: color.jpg (sRGB), normal-gl.jpg (OpenGL normal, non-color), roughness.jpg (non-color), ao.jpg (non-color). Apply with matching UVs and repeat settings. Publisher nominal coverage is 2m wide; inspect repetition and scale at driving-camera distance. AO needs a valid UV channel. Upright blades and terrain silhouettes require separate geometry. Local appearance and Samsung A55 performance are untested. All publisher file sizes and MD5 checksums matched; image decoding verified using sips.
